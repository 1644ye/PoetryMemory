# PoetryMemory 1.6.0

日期：2026-11-05。

## 本次变化

- 独立 Android 包名和源码命名空间 `org.poetrymemory`，独立 `PoetryApp`、`poetry-memory.db`、凭据别名及应用图标。
- 删除静读书架、小说阅读器和相应界面测试；保留可兼容的内容协议、模板、下载与同步规则。背诗工程没有对静读工程目录的构建依赖。
- 本地导入和书源列表聚焦诗集，普通正文导出只包含诗集。
- 新增按书抽背设置页，可选一本或多本来源书籍；按稳定书籍 ID 取全部诗文，不把首页筛选误用到整本书。
- 题型、权重、题数、轮数和重复策略分别设置；固定底部开始按钮；学习会话保存范围名称和正文快照。
- 底部“书库 / 学习 / 收藏 / 我的”导航，设置分类进入子页；阅读和编辑的次要操作进入菜单，评分固定在答题页底部。

## 自动验证

Windows、JDK 21、SDK 36、API 36 模拟器。

- JVM 核心规则测试 52 项通过。
- 新包名下全部 Android 测试 73 项通过，结果保存于 `verification/1.6.0/android-regression.txt`。
- Debug、AndroidTest、非调试 Release 构建通过；Lint 0 错误、23 警告。
- 模拟器同时安装 `org.poetrymemory` 和 `org.quietreader`，两个包均存在。新的应用数据库位于自身沙箱。

重点测试：从“甲本”书籍明细启动抽背，所有题目都来自甲本，范围名称保存为甲本；同名不同 ID 书籍、多个书籍以及空选择的候选隔离；阅读页“更多 → 编辑”真实操作；草稿及版本比较；抽背评分、跳过与历史；原有协议、数据、授权、下载与更新规则回归。

## 安装与数据

1.6.0 为独立安装，不覆盖旧版使用 `org.quietreader` 包名的静读或背诗 1.5.0，也不自动读取其数据。需要原诗文时，请从旧应用导出诗集 JSON，再在背诗主动导入。后续背诗版本沿用 `org.poetrymemory` 和相同签名覆盖升级。

本轮未进行真实账号的私有 GitHub 联调、长期后台调度及实体设备升级验证；这些不计为实测通过。
